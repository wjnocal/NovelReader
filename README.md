# NovelReader

NovelReader 是一款 Android 本地小说阅读器，支持 TXT、EPUB 导入、在线搜书下载、章节阅读、书签笔记、阅读统计和自建 WebDAV 多端同步。

当前版本：`3.111`

## 下载

- [下载最新 APK](https://github.com/wjnocal/NovelReader/releases/latest/download/novelreader.apk)
- [查看全部版本](https://github.com/wjnocal/NovelReader/releases)

当前提供 Android 7.0（API 24）及以上可安装的 APK。若设备上已安装由其他签名生成的同包名版本，请先卸载旧版本再安装。

## 功能

- 导入本地 TXT 和 EPUB，并自动建立书籍、章节和阅读目录。
- 支持滚动阅读和分页阅读，可调整阅读主题、字体、字号、行距、段落间距、首行缩进和页边距。
- 书架支持分类、置顶、搜索、排序、网格/列表视图和书架背景设置。
- 长按书籍可以查看详情、修改分类、标记在读、多选、改名、删除和置顶。
- 阅读过程中支持目录、书签、笔记、评论和文本选择。
- 记录阅读进度、阅读时长、每日阅读统计和连续阅读天数。
- 支持首次使用新手教程以及主页入门清单。
- 支持 JSON 手动备份和恢复。
- 支持用户配置自己的 WebDAV 服务器，同步书架内容、书籍文件、章节、封面、分类、书签、笔记、阅读进度、阅读设置、用户名、头像和阅读统计。
- WebDAV 密码使用 Android Keystore 加密保存，断开账号只清除本机配置，不删除服务器数据。

## 在线搜书

从主页进入“在线搜书”，可以选择搜索方式、下载格式和要使用的书源。搜索结果会合并同名书籍，再让用户选择具体书源版本；每个版本会显示书源和最新章节信息。

本功能的书源组织、搜索、目录解析和正文抓取思路参考并学习自 [freeok/so-novel](https://github.com/freeok/so-novel)，并根据本项目的 Java/XML 架构和阅读数据结构进行了适配。

在线下载支持进度显示、取消下载和后台下载。TXT 和 EPUB 均可选择，章节数量以书源实际提供的目录为准。不同书源的目录、正文格式、限流策略和可用性可能不同。

### 书源说明

书源配置位于 [`app/src/main/assets/online_sources.json`](app/src/main/assets/online_sources.json)，具体数量和启用状态以该配置文件为准。应用支持站内搜索书源和仅通过详情页 URL 下载的书源；部分书源可能因为限流、代理、Cloudflare、JavaScript 渲染或网站改版而暂时停用。

书源是第三方网站提供的公开页面解析规则，可能因为网站改版、域名变化、限流、代理或网络环境而失效。应用不会托管或提供小说内容。使用在线功能时请遵守书源网站规则、版权要求和所在地区法律法规。

## WebDAV 同步

### 配置方式

1. 在主页点击头像。
2. 进入“登入账号”。
3. 填写 WebDAV 地址、用户名和密码。
4. 点击“测试连接”，确认服务器可用后点击“保存并登入”。
5. 可以在同步页面点击“立即同步”，也可以使用前台自动同步。

坚果云等服务通常需要使用 WebDAV 专用密码或应用密码，而不是网页登录密码。坚果云常用地址格式为：

```text
https://dav.jianguoyun.com/dav/
```

不同服务商的地址可能不同，请以服务商提供的 WebDAV 地址为准。服务器需要允许创建目录、上传文件、下载文件、移动文件和删除文件。

### 同步内容

同步数据保存在服务器的 `NovelReaderSync` 目录中，包括：

- 书籍原文件、封面和章节内容。
- 书架、分类、置顶状态、书籍排序和阅读进度。
- 书签、笔记、评论和删除记录。
- 阅读设置、阅读统计事件、用户名和头像。

书架背景图片和透明度不会同步；本地导入记录和本地文件 URI 也不会同步，因为它们只对创建它们的设备有效。下载到其他设备的书籍会在该设备重新建立本地目录，不会复用原设备的绝对路径。

同步会先合并本地和云端内容，再把双方新增内容补充到云端和本地。同名书籍会合并为同一本；书签、笔记和评论保留双方内容，阅读进度发生冲突时由用户选择保留哪一侧。网络失败、认证失败或文件校验失败时会保留本机数据。

## 手动备份

应用原有的 JSON 手动备份和恢复功能仍然独立保留。手动备份文件与 WebDAV 内部同步目录互不兼容，请不要直接修改 WebDAV 目录中的同步文件。

## 开发者

项目使用 Java + XML，主要依赖包括 AndroidX、Material、Room、Jsoup 和 OkHttp。

环境要求：

- Android Studio
- JDK 11
- Android SDK 36.1
- Android 设备或模拟器 API 24 及以上

用 Android Studio 打开项目根目录，等待 Gradle 同步后即可运行 `app` 模块。Windows 命令行也可以使用：

```powershell
./gradlew.bat assembleDebug
```

## 添加或修改书源

书源使用 JSON 配置，不需要修改数据库结构。每个书源通常包含以下内容：

- `id`：书源唯一标识。
- `name`：显示名称。
- `baseUrl`：站点地址。
- `search`：搜索请求、结果选择器、书名、作者和最新章节选择器。
- `book`：详情页信息选择器。
- `toc`：目录选择器。
- `chapter`：章节标题、正文和过滤规则。
- `crawl`：超时、间隔、重试次数和并发数。

修改后请确认 JSON 格式正确，并根据目标站点的实际 HTML 结构调整 CSS 选择器。对于依赖 JS 渲染、Base64 解码、Cloudflare 验证或复杂加密参数的站点，仅修改 CSS 选择器通常无法恢复。

## 项目结构

```text
app/src/main/java/com/wjnocal/novelreader/
├── data/       Room 数据库、实体和 DAO
├── online/     在线书源、搜索和后台下载
├── parser/     TXT、EPUB 导入与章节解析
├── sync/       WebDAV 客户端、归档和同步仓库
└── ui/         书架、阅读器和列表适配器
```
